# Project Management Element Decomposition Template
Adapted from Appendix I of *Secrets to Mastering the WBS* (Buchtik, PMI). Use this to decompose the mandatory `Project Management` Level-2 component. Scale it: small projects need only a subset (charter, plan, schedule, budget, risk register, status reports, lessons learned); large programs may use all of it. Every entry is a deliverable (noun), which is what turns the LoE branch into measurable discrete artifacts.
